## 🚀 What is AI4SDG_Insights?
AI4SDG_Insights is a ready-to-use desktop application that helps you explore the United Nations Sustainable Development Goals (SDGs) through the lens of World Bank data. Whether you're a student, researcher, policy enthusiast, or just curious about global development, this tool lets you visualize complex data and read AI-generated policy briefs—all without writing a single line of code.

## ✨ Key Features
- **Interactive Charts & Maps** – See World Bank indicators plotted on dynamic graphs and world maps.
- **Gemini-Powered Policy Briefs** – Get concise, human-readable summaries generated by Google's Gemini AI for any SDG indicator.
- **UNSDG Portfolio Layout** – Inspired by UNDP dashboards, the interface is clean and organized.
- **Search & Filter** – Quickly find data on poverty, education, climate, health, and more.
- **Export Reports** – Save charts and briefs as PDF or PNG for presentations.
- **No Installation Hassle** – Runs on Windows with a simple double-click (Python included).

## 🛠️ Troubleshooting
If the app does not start or you see an error:
1. Make sure your antivirus is not blocking the extracted files (temporarily disable it if needed).
2. Right-click `run_me.bat` and select "Run as administrator".
3. If a firewall prompt appears, click "Allow access".
4. Close other programs that might use port 8501 (like other Streamlit apps or certain games).

For further help, please open an "Issue" on the GitHub page by clicking the "Issues" tab and describing your problem.
